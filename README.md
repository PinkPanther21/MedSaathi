
# Dashboard

A responsive React dashboard built with Tailwind CSS, ReCharts, and Lucide React icons.  
It features real-time visualizations and reusable components — designed to practice advanced React concepts like hooks, and component composition.

---

## Features

- Built with React and Vite  
- Styled using Tailwind CSS    
- State managed with Context API and hooks  
- Responsive layout  
- Lucide React icons for a neat look
